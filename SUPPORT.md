# Support

For product and connector support, email **support@bridgetown.builders** or use
<https://www.bridgetown.builders/contact>. Current user documentation is available at
<https://www.bridgetown.builders/docs/>.

Include the client name, the public resource version, a minimal synthetic example,
and the observed error. Do not send access tokens, customer data, private model
files, or credentials.

Security reports follow [SECURITY.md](SECURITY.md). Support ownership is
`team/support`.
