# Contributing

Bridge Town welcomes focused fixes to the public connector package, documentation,
examples, and model-authoring helpers described in [SOURCE_SCOPE.md](SOURCE_SCOPE.md).

## Contribution boundary

- Open an issue before a material behavior or interface change.
- Keep examples synthetic. Never include customer data, credentials, tokens, or
  vulnerability details in an issue or pull request.
- Add or update focused tests for executable code and keep generated files in sync.
- Do not submit private service code, deployment configuration, provider-submission
  material, or claims about unpublished implementation details.
- Report vulnerabilities through [SECURITY.md](SECURITY.md), not a public issue.

Documentation is owned by `team/developer-experience` and the connector package by
`team/platform-engineering`. Current public documentation: <https://www.bridgetown.builders/docs/>.
