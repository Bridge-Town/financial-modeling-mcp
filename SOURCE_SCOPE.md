# Public and Private Source Boundary

## Published here

This repository publishes the connector package, current user documentation,
synthetic examples, and versioned model-authoring helpers identified by the canonical
resource inventory:

- Connector package: <https://github.com/Bridge-Town/financial-modeling-mcp>
- Documentation: <https://www.bridgetown.builders/docs/>
- Helper source: <https://github.com/Bridge-Town/financial-modeling-mcp/releases/tag/model-authoring-helpers-v1.1.0>
- Releases: <https://github.com/Bridge-Town/financial-modeling-mcp/releases>

These files are licensed under [LICENSE](LICENSE). The repository does not contain
customer data, credentials, or production configuration.

## Not published here

The hosted Bridge Town service implementation and its operational configuration are
proprietary and are not represented as open source. Public interfaces and behavior
are documented without disclosing private code or internal topology. Provider
directory submission forms and reviewer-only evidence are also outside this public
source package.

Privacy terms remain authoritative at <https://www.bridgetown.builders/privacy>. Questions about the public
boundary go to the support route in [SUPPORT.md](SUPPORT.md).
