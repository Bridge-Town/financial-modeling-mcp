# Security Policy

## Report a vulnerability

Email **security@bridgetown.builders**. Do not open a public issue or include
customer data, credentials, tokens, or exploit details in a public discussion.

The coordinated-disclosure policy, scope, safe-harbor terms, and response targets
are maintained at <https://www.bridgetown.builders/security> by `team/security`.

## Repository scope

Reports may cover this repository's public connector package, documentation,
examples, and helper source. The hosted Bridge Town service is operated separately;
its implementation is not published in this repository, but suspected service
vulnerabilities should be reported through the same private channel.
